AfghanConnect starter — free prototype

FILES
- index.html: prototype with search, categories, and French/Dari/Pashto/English UI labels
- manifest.json: installable web app metadata
- sw.js: basic offline cache
- icon.svg: app icon

IMPORTANT
- All directory listings are fictional examples. Replace them only with verified details and permission.
- This first version is a static prototype. It does not yet have a secure admin dashboard or shared database, so edits in the code are not automatically synchronized for all users.
- The free hosting provider may have limits. A custom domain is not included.
- Do not collect immigration papers, health data, or other sensitive documents in this prototype.

HOW TO TEST
Open index.html in a browser to preview basic functions. Installation and offline features require hosting over HTTPS (or localhost).

FREE HOSTING PATH (GitHub Pages)
1. Create a GitHub account at https://github.com/
2. Create a new public repository named afghanconnect.
3. Upload index.html, manifest.json, sw.js, and icon.svg to the repository root.
4. In repository Settings -> Pages, choose deployment from the main branch and root folder, then save.
5. After GitHub publishes it, open the Pages URL. It should be an HTTPS address.
6. Test search and language selector on your phone.
7. On Android, open the link in Chrome and use Install app / Add to Home screen. On iPhone, open the link in Safari, tap Share, then Add to Home Screen.

NEXT
